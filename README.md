# Smart Multilingual Support Assistant

## Summary
AI system for classifying customer complaints and generating multilingual responses.

## Features
- Intent classification
- Urgency detection
- English + Arabic output
- Structured JSON validation
- Human escalation logic

## Why this problem
Returns and delivery issues are high-impact problems in e-commerce platforms like Mumzworld.

## Run
pip install -r requirements.txt  
python app.py

## Tooling
- OpenRouter (LLM)
- Gradio (UI)
- Pydantic (validation)
- Cursor for code generation and refactoring
